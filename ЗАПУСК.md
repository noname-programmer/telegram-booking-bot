# 🚀 Запуск бота с нуля: пошаговая инструкция

Время: около 15 минут. Нужен компьютер (Windows, macOS или Linux) и Telegram.

Есть два варианта:
- **А. Telegram Serverless:** бесплатный хостинг у Telegram, но эта функция пока включена не у всех ботов. Проверь: @BotFather → `/mybots` → твой бот. Если там есть кнопка **Serverless**, выбирай этот вариант (шаги 1–7 ниже).
- **Б. Свой сервер или компьютер:** работает у всех. Смотри раздел [«Вариант Б»](#вариант-б-без-serverless-свой-сервер-или-компьютер) в конце.

---

## Шаг 1. Установи Node.js (один раз)

1. Открой https://nodejs.org и скачай версию **LTS**.
2. Установи, нажимая «Далее» и ничего не меняя.
3. Проверь: открой терминал (Windows: нажми `Win`, напиши `cmd`, Enter) и введи:
   ```bash
   node -v
   ```
   Должно появиться что-то вроде `v22.x.x`. Если пишет «не найдено», перезагрузи компьютер.

## Шаг 2. Создай бота в Telegram

1. Открой [@BotFather](https://t.me/BotFather) и отправь `/newbot`.
2. Придумай имя (например, `Tabassum Clinic`) и username, который заканчивается на `bot` (например, `tabassum_booking_bot`).
3. В @BotFather: `/mybots` → твой бот → **Serverless** → **включи**.
4. Там же: **CLI Access** → **Access token**. Скопируй его: он понадобится на шаге 4.

> ⚠️ Никому не отправляй этот токен и не выкладывай его на GitHub. Он хранится в папке `.tgcloud/`, которая уже исключена из git.

## Шаг 3. Скачай проект

Если проект на GitHub, нажми зелёную кнопку **Code → Download ZIP** и распакуй архив. Затем в терминале перейди в папку проекта:

```bash
cd путь/к/booking-bot
```

(Подсказка для Windows: открой папку в Проводнике, кликни на адресную строку, напиши `cmd` и нажми Enter: терминал откроется сразу в этой папке.)

Установи инструменты:

```bash
npm install
```

## Шаг 4. Подключи бота к проекту

```bash
npx tgcloud login
```

Вставь токен из шага 2 (CLI Access) и нажми Enter.

## Шаг 5. Загрузи бота в облако

```bash
npx tgcloud push
```

Затем создай таблицы базы данных:

```bash
npx tgcloud migrate
```

Он спросит подтверждение: нажми `y`.

## Шаг 6. Проверь

Открой своего бота в Telegram и нажми **Start**. Появится меню. Запишись на любое время.

## Шаг 7. Сделай себя админом

1. Отправь боту `/myid` и скопируй число.
2. Открой файл `tgcloud/lib/config.js` (лучше в редакторе [VS Code](https://code.visualstudio.com)) и впиши ID:
   ```js
   export const ADMIN_IDS = [
     123456789,
   ];
   ```
3. Загрузи изменения:
   ```bash
   npx tgcloud push
   ```
4. Отправь боту `/start`: появится кнопка **🛠 Админка**.

Для клиента впиши в `ADMIN_IDS` **ID владельца бизнеса** (через запятую можно указать несколько человек).

## Как менять бота дальше

| Хочу… | Что делать |
|---|---|
| поменять название, услуги, цены, часы работы, тексты | отредактировать `tgcloud/lib/config.js` → `npx tgcloud push` |
| сделать бота для другого вида бизнеса | скопировать пример из `examples/` в `tgcloud/lib/config.js` → `npx tgcloud push` |
| поменять остальные тексты и кнопки | `tgcloud/lib/ui.js` → `npx tgcloud push` |
| добавить колонку или таблицу в базу | `tgcloud/schema.js` → `npx tgcloud push` → `npx tgcloud migrate` |
| проверить, что ничего не сломал | `npm test` (проверяет основной конфиг и все примеры) |
| посмотреть, что изменилось | `npx tgcloud status` |

## Если что-то не работает

- **Бот молчит.** Выполни `npx tgcloud webhook`. Если пишет *out of sync*, выполни `npx tgcloud webhook sync`.
- **Ошибка про таблицу `no such table`.** Ты забыл `npx tgcloud migrate`.
- **`migrate` ругается на индекс `uidx_bookings_slot`.** Скопируй ошибку целиком и покажи ИИ-ассистенту вместе с файлом `tgcloud/schema.js`.
- **Хочу протестировать код без деплоя.**
  ```bash
  npx tgcloud run handlers/message '{ chat: { id: 1, type: "private" }, from: { id: 1, first_name: "Test" }, text: "/start" }'
  ```
- **Работаешь с ИИ (Claude Code, Cursor).** Открой папку проекта в нём: ассистент сам прочитает `AGENTS.md` и `docs/tgcloud-sdk.md` и будет знать правила платформы.

## Вариант Б: без Serverless (свой сервер или компьютер)

Код бота тот же. Отличие одно: бот работает на машине, которая включена 24/7, а не у Telegram.

### Где запустить

| Вариант | Цена | Для чего |
|---|---|---|
| Твой компьютер | бесплатно | проверить и показать демо. Бот работает, пока компьютер включён |
| VPS (Hetzner, DigitalOcean, местные хостинги Узбекистана) | ~$3–6 в месяц | для клиентов. Заложи эту сумму в абонплату |

### Запуск на компьютере

1. Установи Node.js (шаг 1 выше) и скачай проект (шаг 3).
2. Возьми **обычный токен бота**: @BotFather → `/mybots` → бот → **API Token** (выглядит как `123456:AAH...`).
3. В папке `standalone` скопируй файл `.env.example` и назови копию `.env`. Открой её и впиши токен:
   ```
   BOT_TOKEN=123456:AAH...
   ```
4. В терминале:
   ```bash
   cd standalone
   ```
   ```bash
   npm install
   ```
   ```bash
   npm start
   ```
5. Появится `✅ Бот @твой_бот запущен`. Открой бота в Telegram и проверь. Остановить: `Ctrl+C`.

База данных хранится в файле `standalone/data/bot.db`. Не удаляй его, иначе пропадут записи.

### Запуск на VPS через Docker

На сервере (Ubuntu) с установленным Docker:

```bash
git clone https://github.com/noname-programmer/telegram-booking-bot.git
```
```bash
cd telegram-booking-bot && cp standalone/.env.example standalone/.env && nano standalone/.env
```
Впиши `BOT_TOKEN`, сохрани (`Ctrl+O`, `Enter`, `Ctrl+X`), затем:
```bash
docker compose up -d --build
```

Бот запущен и сам поднимется после перезагрузки сервера. Полезные команды:

| Хочу… | Команда |
|---|---|
| посмотреть логи | `docker compose logs -f` |
| обновить бота после изменений | `git pull && docker compose up -d --build` |
| остановить | `docker compose down` |

### Важно

- **Бот может работать только в одном месте.** Если он был на Serverless, выключи Serverless в @BotFather или запусти с `DELETE_WEBHOOK=1` в `.env`.
- Если бот пишет `409 Conflict`, значит он уже запущен где-то ещё (например, на другом компьютере).
